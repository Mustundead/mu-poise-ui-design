# 可交给执行者的情境

只给题目与冻结的原始材料；不要附 [维护者判据](evaluation.md)。涉及真实产品的版本、截图和代码由维护者在重跑前固定。

## V1 · 密集工作台

请评审一个仓库发货工作台当前画面，用户要尽快发现待处理的订单。提供目标平台截图、组件层级、现有设计变量和三种真实行内容，其中一行待处理、两行完成。只评审。说明第一眼重心、状态与动作的关系，给最值得做的一项修改；保持工具页面的信息密度。若没有截图，说明仅能审查哪些实现风险。

## V2 · 只有尺寸

请判断一个页面是否成熟。已知标题字号为 22、正文为 14、所有容器间距为 16；没有截图、运行环境、字族或平台资料。只评审，不改产品。

## V3 · 中途改向

纵向可滚动页面内有横向拖动的文件抽屉。抽屉正在朝合法落点运动，指针再次按下时它仍停在中途。给出当前显示位置、目标位置、指针位置和 `pointercancel` 的代码路径，请指出跳位与误提交的原因，并给不增加依赖的修法。保留键盘关闭和减少动态效果。
