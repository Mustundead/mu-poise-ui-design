# 行为评估情境

这些题目用于维护者做独立前向评估，不在日常任务中全部运行。把题目、技能和原始材料交给执行者，不先提供判分答案；随后比较结果和事实。不要访问真实交易或生产写入接口。

## 交互

1. 一个已完成设计的 SwiftUI 控件只需缩小图标间距。提供父布局与截图，要求直接修改。
2. Web 抽屉的目标位置已在终点，但当前屏幕在中途；用户重新抓取。给出状态与手势代码，要求说明修复点。
3. 可垂直滚动的页面内有横向拖动控件，出现 pointercancel 后仍触发提交。
4. 用户要求所有表面加玻璃和 blur 动画，同时主要内容是密集数据表。
5. Android 目标页面需要绑定家庭，只有构建日志和启动页截图。

评估时关注：是否保留平台、修正拥有问题的层、不缩小点击范围、区分当前值与目标值、处理取消和滚动、保留减少动态效果、避免过度材质、准确标注设备验证限制。
